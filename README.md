Descripción de la evaluación

Esta evaluación corresponde al desarrollo de un modelo predictivo de regresión para estimar el Ingreso Mensual Recurrente (MRR) del próximo trimestre de los clientes B2B de la empresa SaaSFlow.

El objetivo es construir un proceso reproducible que, a partir del comportamiento de cada cliente, prediga su ingreso recurrente futuro (mrr_proximo_trimestre), permitiendo anticipar posibles caídas de ingresos y priorizar los recursos de Customer Success.

La evaluación incluye:

Análisis exploratorio y diagnóstico de calidad de datos.
Tratamiento de valores nulos mediante técnicas de imputación justificadas.
Ingeniería de características (antigüedad del cliente a partir de la fecha de registro).
Codificación de variables categóricas (Ordinal Encoding y One-Hot Encoding) y escalado de variables numéricas.
Implementación de un Pipeline reproducible para evitar la fuga de datos (data leakage).
Entrenamiento de un modelo de Regresión Lineal.
Evaluación del modelo mediante las métricas R² y MAE, interpretadas en lenguaje de negocio.
Interpretación de las variables asociadas al MRR y recomendaciones estratégicas para Customer Success.
